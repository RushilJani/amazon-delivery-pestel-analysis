# amazon-delivery-pestel-analysis
Amazon Delivery Environmental Impact Analysis using PESTEL Framework A data-driven case study analyzing operational risks and opportunities in last-mile delivery using statistical modeling, hypothesis testing, and Power BI dashboard visualization.
Project Title: Amazon Delivery Environmental Impact Analysis (PESTEL)

This project applies the PESTEL framework to evaluate how political, economic, social, technological, environmental, and legal factors influence operational performance in Amazon last-mile delivery operations. The analysis includes data cleaning, regression modeling, hypothesis testing, and trend forecasting using delivery-level operational data.

A Power BI dashboard was developed to visualize operational performance, delivery delays, environmental factors, and workforce efficiency to support strategic decision-making and supply-chain optimization.

Tools Used: Power BI, Statistical Analysis, Regression Modeling, Data Cleaning, Environmental Risk Analysis

Key Contributions:

Conducted environmental impact assessment using PESTEL methodology

Performed regression and statistical testing to identify delivery performance drivers

Designed an interactive Power BI dashboard for operational insights

Developed strategic recommendations to improve delivery efficiency and risk mitigation
